# Alcohol Reports Dashboard

This repository contains a minimal Next.js + Tailwind scaffold for the Alcohol Reports dashboard (sidebar + basic pages).

Getting started:

1. Install dependencies

   npm install

2. Run dev server

   npm run dev

3. Open http://localhost:3000

What's included:
- Sidebar layout
- Dashboard page (dummy data)
- Reports list page (dummy data)
- Templates/Targets/Generate/Settings placeholder pages
- API route /api/reports returning dummy JSON
